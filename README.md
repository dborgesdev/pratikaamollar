# Pratika Amollar — V1

React + TypeScript + Tailwind + Vite + Cloudflare Worker.

```sh
pnpm install
pnpm dev
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

Leia [especificação](docs/project.md), [integração](docs/integration.md) e [validação](docs/validation.md). Nenhum backend remoto é modificado pelo build. Deploy configurado apenas para preview independente, sem domínio ou DNS.

V2: leia [revisão e medições](docs/v2-validation.md). A versão V2 está somente em prévia local; o preview público anterior não foi atualizado.
